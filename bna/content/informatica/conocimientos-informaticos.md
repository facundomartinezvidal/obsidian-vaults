# Conocimientos Informáticos (Sección 1)

Cubre **Excel, Word, PowerPoint** y **uso general de PC**. Múltiple choice. Abajo lo más "tomable".

## Excel

### Funciones básicas (memorizar qué hace cada una)
| Función | Qué hace |
|---------|----------|
| `SUMA` | suma un rango |
| `PROMEDIO` | media aritmética |
| `MAX` / `MIN` | mayor / menor valor |
| `CONTAR` | cuenta celdas con **números** |
| `CONTARA` | cuenta celdas **no vacías** (texto incluido) |
| `CONTAR.SI` | cuenta según una condición |
| `SUMAR.SI` | suma según una condición |
| `SI` | condicional (si-entonces-sino) |
| `BUSCARV` (VLOOKUP) | busca un valor en la 1ª columna y devuelve otro de la misma fila |
| `PROMEDIO.SI` | promedio con condición |
| `CONCATENAR` / `&` | une textos |

### Conceptos clave
- **Referencia relativa** `A1` → cambia al copiar. **Absoluta** `$A$1` → fija (el `$` fija fila/columna). Mixta: `$A1` / `A$1`.
- Toda fórmula empieza con **`=`**.
- **Filtros:** permiten mostrar solo filas que cumplen un criterio (Datos → Filtro). No borran datos, los ocultan.
- **Ordenar:** de A-Z / Z-A o por valores.
- **Gráficos:** columnas/barras (comparar), líneas (evolución en el tiempo), torta/circular (proporción de un total).
- **Celda:** intersección fila+columna (ej. B3). **Rango:** conjunto de celdas (ej. A1:A10).

## Word

- **Diseño de página:** orientación (vertical/horizontal), tamaño de hoja (A4, carta), **márgenes**.
- **Encabezado y pie de página:** texto repetido arriba/abajo de cada página (números de página, título).
- **Fuente (tipografía):** tipo de letra (Arial, Times New Roman, Calibri), tamaño (en puntos), negrita/cursiva/subrayado.
- **Interlineado:** espacio entre líneas (1, 1.5, doble).
- **Estilos:** formatos predefinidos (Título 1, Normal…).
- Alineación: izquierda, centrada, derecha, justificada.

## PowerPoint

- **Diapositiva (slide):** cada "página" de la presentación.
- **Vistas (barra inferior derecha):** Normal · Clasificador de diapositivas · Vista de lectura · **Presentación con diapositivas**.
- **Modo Presentación** (pantalla completa) → tecla **F5** (desde el inicio) o **Shift+F5** (desde la diapositiva actual). Ícono del proyector.
- **Transiciones:** efecto al **pasar** de una diapositiva a otra.
- **Animaciones:** efecto sobre un **elemento** dentro de la diapositiva (texto, imagen).
- **Patrón de diapositivas:** plantilla que define el diseño común.

## Uso general de PC

### Backup / Copia de seguridad
**Copia de seguridad de archivos** (para recuperarlos si se pierden/dañan). No es mantenimiento ni mejora de rendimiento.

### Atajos de teclado (los más preguntados)
| Atajo | Acción |
|-------|--------|
| `Ctrl + C` | Copiar |
| `Ctrl + X` | Cortar |
| `Ctrl + V` | Pegar |
| `Ctrl + Z` | Deshacer |
| `Ctrl + Y` | Rehacer |
| `Ctrl + S` | Guardar |
| `Ctrl + P` | Imprimir |
| `Ctrl + A` | Seleccionar todo |
| `Ctrl + F` | Buscar |
| `Ctrl + B` | Negrita (Word) |
| `Alt + Tab` | Cambiar entre ventanas |
| `Ctrl + Alt + Supr` | Administrador de tareas / bloquear |
| `Impr Pant` | Captura de pantalla |

### Mail (correo electrónico)
- **Para (To):** destinatario principal.
- **CC (con copia):** copia visible a otros.
- **CCO (con copia oculta / BCC):** copia que los demás **no ven**.
- **Adjunto:** archivo que se envía con el mail.
- **Asunto:** título del mensaje.

### Otros conceptos
- **Hardware** = parte física (teclado, CPU, monitor). **Software** = programas.
- **Navegador** (Chrome, Firefox) ≠ **buscador** (Google).
- **Nube (cloud):** almacenamiento en internet (Drive, OneDrive).
- **Archivo vs Carpeta:** carpeta contiene archivos.
- Extensiones: `.xlsx` Excel · `.docx` Word · `.pptx` PowerPoint · `.pdf` PDF.

> [!tip] Estrategia
> Son preguntas de conocimiento general de Office/PC. Si dudás: las respuestas correctas suelen ser las **estándar y simples** (Backup = copia de seguridad; Ctrl+C = copiar). Los distractores inventan funciones raras.
