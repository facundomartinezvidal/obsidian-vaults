Ejercicio 2:

La solucion es dividir el arreglo a la mitad tomando el valor medio cada vez.
este valor medio debe compararse con sus elementos vecinos para ver que
se trata o no de la maxima altura. si mid es la altura maxima se retorna
ese valor, sino me fijo que el siguiente valor sea mayor, es decir, creciente
y si es asi, el pico esta en la mitad derecha, sino en la izquierda.

public static int altitud(int[] A, int ini, int fin){
        if (ini < fin){
            int mid = ini + (fin-ini)/2;
            if (A[mid] < A[mid+1]){
                return altitud(A, mid+1, fin);
            }else
                return altitud(A, ini, mid);
        }else
            return A[fin];
    }
a=1 b=2 k=0 O(log n)
