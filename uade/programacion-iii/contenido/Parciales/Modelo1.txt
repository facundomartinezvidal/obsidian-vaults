EJERCICIO 3:

Se empleara Programacion dinamica porque se trata de un problema el cual se
puede reducir en subproblemas y obtener una solucion optima en base a soluciones
optimas anteriores.

Algoritmo (int N, K)
	crearMatriz(P)
	for n in range N+1
		for k in range K+1
			if (k == 0)
				P[n,k] = 1
			else if (n < k)
				P[n,k] = 0
			else 
				P[n,k] = P[n-1,k] + k * P(n-1, k-1)
				
O(n2)
