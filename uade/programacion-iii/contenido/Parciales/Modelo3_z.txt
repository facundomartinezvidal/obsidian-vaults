EJERCICIO 3.
	a. si M[i,j] != 2, H[i,j] = M[i,j] + max(H[i-1,j], H[i,j-1])
		sino si M[i,j] == 2, H[i,j] = -1
	b. Programacion dinamica, resolviendo subproblemas dependientes.
	c.
		Algoritmo (Matriz M)
			crear matriz H
			
			for i in range(M.length)
			
				for j in range(M.length)
					
					if M[i,j] == 2
						H[i,j] = -1
					else if (i == 0 and j == 0)
						H[i,j] = M[i,j]
					else if (i == 0)
						if H[i,j-1] != -1
							H[i,j] = M[i,j] + H[i,j-1]
						else
							H[i,j] = -1
					else if (j == 0)
						if H[i-1,j] != -1
							H[i,j] = M[i,j] + H[i-1,j]
						else
							H[i,j] = -1
					else
						maximo = max(H[i-1,j], H[i,j-1])
						if maximo == -1
							H[i,j] = -1
						else 
							H[i,j] = M[i,j] + maximo
