# Clase 2 — Actividad: Prompt Battle — ¿Qué IA responde mejor?

**Vencimiento:** 17 de agosto 2026, 23:59hs — permite múltiples entregas.

## Datos generales

- **Duración:** 30 minutos
- **Modalidad:** individual o parejas
- **Herramientas:** ChatGPT, Gemini, Copilot, Claude, DeepSeek u otro asistente disponible
- **Objetivo:** experimentar cómo cambia calidad de respuesta al mejorar prompt, comparar comportamiento entre asistentes distintos

## Problema base (igual para todos)

> Una universidad quiere implementar un sistema de asistencia basado en IA para ayudar a estudiantes universitarios a organizar sus materias, detectar riesgos académicos y recomendar acciones de estudio. El sistema tendrá acceso a información académica de los estudiantes.

Objetivo: lograr que una IA produzca propuesta concreta para este sistema, mediante tres niveles de prompt.

## Nivel 1 — Prompt pobre (5 min)

Prompt deliberadamente simple, sin instrucciones extra.

Ejemplo: *"Diseñá un sistema de IA para ayudar a estudiantes universitarios."*

Ejecutar mismo prompt en dos asistentes distintos (ej: ChatGPT + Gemini, o Claude + DeepSeek). Guardar ambas respuestas.

**Pregunta rápida:** ¿qué diferencias encontraron entre las respuestas?

## Nivel 2 — Prompt mejorado (8 min)

Incorporar como mínimo:

- Rol de la IA
- Contexto
- Objetivo
- Usuario destinatario
- Restricciones
- Formato esperado

Ejemplo conceptual: *"Actuá como arquitecto de soluciones de IA especializado en educación universitaria..."* (no se da prompt completo, hay que construirlo).

Ejecutar en mismos dos asistentes.

**Comparar:**
- ¿Respuesta más específica?
- ¿Menos información irrelevante?
- ¿Estructura mejoró?
- ¿Asistente comprendió mejor el problema?
- ¿Los dos asistentes reaccionaron igual?

## Nivel 3 — Prompt profesional (10 min)

Debe incluir obligatoriamente:

1. **Rol** — ¿quién debe ser la IA?
2. **Contexto** — ¿qué problema resuelve?
3. **Objetivo** — ¿qué resultado se busca?
4. **Usuarios** — ¿para quién está diseñado?
5. **Restricciones**, por ejemplo:
   - No utilizar información sensible innecesaria
   - No realizar diagnósticos
   - No tomar decisiones automáticamente
   - Solución viable para una universidad
   - Contemplar privacidad y seguridad
6. **Criterios de calidad** — respuesta concreta, técnicamente viable, clara, justificable, orientada a implementación real
7. **Formato de salida**, por ejemplo:
   - Problema
   - Propuesta de solución
   - Arquitectura conceptual
   - Funcionalidades
   - Riesgos
   - Controles de seguridad
   - Ejemplo de interacción
   - Recomendaciones de implementación
8. **Autoverificación** — agregar al prompt: *"Antes de entregar la respuesta, verificá si cumpliste todos los requisitos. Si detectás incumplimientos, corregilos antes de presentar la respuesta final."*

Ejecutar prompt profesional en los mismos dos asistentes.

## Parte competitiva

Elegir cuál IA produjo mejor respuesta — **justificado**, no alcanza con "ChatGPT fue mejor".

## Preguntas finales (entregable)

1. ¿Qué cambió entre el prompt 1, el prompt 2 y el prompt 3?
2. ¿El mejor prompt produjo necesariamente la mejor respuesta? ¿Por qué?
3. ¿Qué diferencias observaste entre los asistentes de IA?
4. ¿El resultado depende más del modelo utilizado o de la calidad del prompt? Justificar con evidencia obtenida durante la actividad.

## Única regla

No está permitido pedirle a otra IA que construya o mejore el prompt durante la actividad.

No gana quien obtiene la respuesta más larga. Gana quien consigue la respuesta más útil con el menor nivel de ambigüedad.
